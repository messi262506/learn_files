## 教程内容概览

该教程涵盖以下内容：

1. **配置身份** — 设置 Git 用户名和邮箱
2. **整理文件夹** — 创建统一的毕业设计项目目录
3. **初始化仓库** — `git init` 创建本地仓库
4. **创建 .gitignore** — 排除 Word 临时文件和系统文件
5. **第一次提交** — `git add` / `git commit` 基本流程
6. **推送到 GitHub** — 创建远程仓库并关联推送
7. **日常使用流程** — 每次修改后的三步操作
8. **常用命令速查** — status、log、diff、pull、checkout 等命令
9. **分支工作流** — 可选进阶：使用分支管理导师修改
10. **注意事项** — 提交频率、push 顺序、冲突避免等提醒

## 适用对象

- 需要使用 Git/GitHub 管理毕业设计论文的学生
- Git 零基础用户，按教程顺序操作即可上手
